iconeZERA

Free SVG icons, straight into your slide and your Photoshop canvas.

Type what you need — in any language —, press Enter and click the icon. In PowerPoint it lands as an editable SVG; in Photoshop, as a vector Smart Object in the color and size you choose.

Download for Photoshop (.ccx) Download for PowerPoint (manifest)

How to install

Photoshop (2026 or Beta, version 24 or later)

  1. Download iconezera-photoshop.ccx with the button above.
  2. Double-click it. The Creative Cloud app installs the plugin.
  3. In Photoshop, open Plugins → iconeZERA.

PowerPoint for the web

  1. Download the manifest with the button above.
  2. At powerpoint.office.com, open a presentation → Insert → Add-ins → Upload My Add-in and pick the file.

PowerPoint for Windows and Mac

Until iconeZERA is listed on AppSource, installation is by sideloading: on Windows, share a folder containing the manifest and register it under File → Options → Trust Center → Trusted Add-in Catalogs; on Mac, copy the manifest to ~/Library/Containers/com.microsoft.Powerpoint/Data/Documents/wef and reopen PowerPoint. In organizations, the Microsoft 365 admin can deploy it to everyone under Admin center → Integrated apps.

How it works

  1. Open the panel: Home → iconeZERA in PowerPoint, or Plugins → iconeZERA in Photoshop.
  2. Type a term (or select a word on the slide / a text layer before opening the panel).
  3. Click the icon. In PowerPoint, recolor it or convert it to a shape; in Photoshop, pick color and size in the bottom bar before clicking.

200,000+ open source icons via Iconify, limited to collections whose license requires no attribution (MIT, Apache 2.0, ISC, CC0 and similar). Free, no account, no ads.

Common problems

  • The icon wasn't inserted: click an empty area of the slide and try again.
  • No results: try a simpler term or switch the language with the globe button in the panel.
  • It came in as an image, not SVG: older Office versions don't accept SVG; the panel falls back to PNG.
  • Photoshop: "Open a document": the plugin only inserts into an open document.

Baixar para Photoshop (.ccx) Baixar para PowerPoint (manifest)

Como instalar

Photoshop (2026 ou Beta, versão 24 ou superior)

  1. Baixe o arquivo iconezera-photoshop.ccx pelo botão acima.
  2. Dê dois cliques nele. O app Creative Cloud instala o plugin.
  3. No Photoshop, abra Plug-ins → iconeZERA.

PowerPoint Web

  1. Baixe o manifest pelo botão acima.
  2. Em powerpoint.office.com, abra uma apresentação → Inserir → Suplementos → Carregar meu suplemento e escolha o arquivo.

PowerPoint para Windows e Mac

Enquanto o iconeZERA não está no AppSource, a instalação é por sideload: no Windows, compartilhe uma pasta com o manifest e cadastre-a em Arquivo → Opções → Central de Confiabilidade → Catálogos de Suplementos Confiáveis; no Mac, copie o manifest para ~/Library/Containers/com.microsoft.Powerpoint/Data/Documents/wef e reabra o PowerPoint. Em empresas, o administrador do Microsoft 365 pode instalar para todos em Centro de administração → Aplicativos integrados.

Como funciona

  1. Abra o painel: Página Inicial → iconeZERA no PowerPoint, ou Plug-ins → iconeZERA no Photoshop.
  2. Digite um termo (ou selecione uma palavra no slide / uma camada de texto antes de abrir o painel).
  3. Clique no ícone. No PowerPoint, recolora ou converta em forma; no Photoshop, escolha cor e tamanho na barra inferior antes de clicar.

Mais de 200 mil ícones open source via Iconify, apenas de coleções cuja licença dispensa crédito ao autor (MIT, Apache 2.0, ISC, CC0 e similares). Gratuito, sem conta, sem anúncios.

Problemas comuns

  • O ícone não foi inserido: clique em uma área vazia do slide e tente de novo.
  • Nenhum resultado: tente um termo mais simples ou troque o idioma no globo do painel.
  • Entrou como imagem, não SVG: versões antigas do Office não aceitam SVG; o painel usa PNG automaticamente.
  • Photoshop: "Abra um documento": o plugin só insere com um documento aberto.
